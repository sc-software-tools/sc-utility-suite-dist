# Contributing to SC Utility Suite

Thank you for your interest in **SC Utility Suite**! We are committed to building fast, lightweight, and privacy-first Windows desktop utilities.

---

## How to Report Bugs

If you encounter unexpected behavior or an issue:
1. Search the [Issues](https://github.com/sc-software-tools/sc-utility-suite-dist/issues) tab to see if the issue has already been reported.
2. If not, open a new issue using our **Bug Report** form.
3. Include your Windows version (Windows 10 or Windows 11, 64-bit), the specific application name, and steps to reproduce the issue.

---

## Suggesting Enhancements

We welcome ideas that make everyday desktop tasks quicker and simpler. When suggesting features:
- Use the **Feature Request** form.
- Keep in mind our core philosophy: 100% offline local processing, zero telemetry, no recurring subscriptions, and clean Windows 11 Fluent interfaces.

---

## Security Vulnerabilities

Please do not report security vulnerabilities via public GitHub issues. Refer to [SECURITY.md](SECURITY.md) or email us directly at `sc-developer@outlook.com`.
