How to Open RAR and 7z Files on Windows and Linux

RAR and 7z are common for downloads and shared folders, but older Windows versions can't open them, and some tools nag you to buy a licence. Here's what works.

Windows 11: try File Explorer first

Recent Windows 11 updates can extract RAR and 7z files from File Explorer: right-click the file and choose Extract All. If that option is missing (Windows 10 or older Windows 11), or the archive is password-protected or split into parts, use a dedicated tool.

Linux: use your package manager or a desktop app

Most desktops open ZIP and TAR out of the box. For RAR and 7z install unrar and 7zip (or p7zip), or use Archive Unpacker from the Snap Store, a .deb or a .tar.gz.

Watch out for unsafe archives

A badly made or malicious archive can try to write files outside the folder you chose. Archive Unpacker checks every path and blocks this.

Step by step with Archive Unpacker

  1. Install Archive Unpacker. Free from the Microsoft Store, the Snap Store, or as an installer or package from the Archive Unpacker page.
  2. Open the archive. Double-click it, drag it into the window, or right-click it in File Explorer and choose Extract.
  3. Check what's inside. Browse the file list before extracting.
  4. Enter the password if asked. Password-protected archives prompt for the password.
  5. Extract. Pick a folder and extract. You can also create ZIP files from your own folders.
