How to Merge PDF Files Offline on Windows and Linux

Merging PDFs is easy on websites, but those sites see every page you upload: contracts, payslips, medical letters. Here's how to do it on your own computer instead.

Why not use an online PDF merger?

Online tools upload your files to their servers. Even with good intentions, you can't check what happens to them afterwards. For anything personal or confidential, an offline tool is the safer choice.

On Linux, there's also a command line option

If you're comfortable with a terminal, qpdf --empty --pages a.pdf b.pdf -- merged.pdf merges files (install the qpdf package first). PDF Knife does the same with drag and drop.

Step by step with PDF Knife

  1. Install PDF Knife. Free from the Microsoft Store, or as an installer, portable ZIP or Linux package from the PDF Knife page.
  2. Add the PDFs. Drag the files into the window in any order.
  3. Put them in order. Use the arrows to move each file up or down. The merged document follows this order.
  4. Merge. Choose Merge and save. Your new PDF opens in the output folder.
  5. Need only some pages?. Use Extract and type a range such as 3-7, or Burst to save every page as its own file.
