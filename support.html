Bug Reports & Issues

Found a crash or platform-specific issue on Windows, Linux, or Android? Open a public issue on GitHub.

Open GitHub Issue ↗

What to Include in a Bug Report

  • App name & version: Check Settings → About inside the app (for example, 1.1.2 on desktop or 1.0.6 on Android).
  • Platform & package type: Windows (Installer / Portable ZIP / Microsoft Store), Linux (.deb / .tar.gz / Snap), or Android.
  • Steps to reproduce: What file type or action triggered the issue, and any message shown in the status bar.

PRO Licensing & Restore Help

  • Microsoft Store & Google Play: Purchases are tied to your Microsoft or Google account. Open PRO → Restore purchase if you reinstall or switch devices.
  • Standalone (Windows Installer / Portable ZIP / Linux): Enter your Gumroad licence key in Upgrade to PRO, or click Restore if activation was interrupted.
  • Need a licence key resent? Email sc-developer@outlook.com with your Gumroad receipt email.

Open-Source & FFmpeg Source Code

Media Trim, HEIC Studio, and Screen Lens bundle FFmpeg (LGPL/GPL). Corresponding source archives and build records are published alongside releases at GitHub Releases, or available on request from sc-developer@outlook.com.
