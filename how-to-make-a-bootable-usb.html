How to Make a Bootable USB Drive from an ISO (Windows and Linux)

To install Linux, reinstall Windows or run a rescue tool, you need the ISO image written to a USB stick, not just copied onto it. Here's how to do it safely.

Before you start

You need the ISO file, a USB stick at least as big as the image (8 GB is usually enough), and a backup of anything on the stick: writing an image erases the whole drive.

Choosing a tool

Well-known free tools include Rufus (Windows) and balenaEtcher. USB Flasher focuses on safety: it lists only removable USB drives, never your system disks, and asks you to confirm the exact drive before erasing anything.

Windows installer ISOs

Microsoft's own Media Creation Tool is the simplest way to make a Windows 10 or 11 installer, because Windows ISOs contain a file too large for some USB formats.

Step by step with USB Flasher

  1. Install USB Flasher. Free for Windows (installer or portable) and Linux (Snap Store, .deb, .tar.gz) from the USB Flasher page.
  2. Choose the image. Select your .iso, .img or .bin file.
  3. Pick the USB drive. Only removable drives are listed. Check the size and name carefully.
  4. Confirm and write. Confirm the drive. Everything on it is replaced by the image.
  5. Verify. Let USB Flasher verify the drive after writing, then boot from it.
