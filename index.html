A FEW THINGS TO KNOW

Simple tools. Clear answers.

Are these free trials?

No. Each app has a permanent free edition. Some actions have limits, such as five photos per conversion batch or three minutes per recording. You can keep using the free features without paying.

Do I need to install the whole suite?

No. Choose any app on its own, or use the bundle to download all seven together. You do not need an account for free file-processing features.

Are my files uploaded anywhere?

No. File processing happens on your PC. Pro purchases and activation contact Microsoft Store or Gumroad; standalone activation initially needs an internet connection. The desktop apps do not run background analytics. This website uses GoatCounter for page views and download/Store-link click counts.

Which Windows versions are supported?

64-bit Windows 10, version 2004 (build 19041) or later, and Windows 11. Standalone downloads include the .NET runtime; Media Trim and Screen Lens also include FFmpeg.

Where can I get help?

For questions or a problem with an app, email sc-developer@outlook.com. Include the app name, what you were doing and any error message. Please avoid sending private files.

Verify a download (SHA256 checksums)

Download the v1.0.1 checksum list for the original sixteen installer and ZIP files. The current standalone checksum list covers the updated installers and ZIPs, including Media Trim 1.0.3. In PowerShell, run Get-FileHash -Algorithm SHA256 <file> and compare its SHA256 value with the matching filename. Hashes confirm download integrity, not publisher identity.
